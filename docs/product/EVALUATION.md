# 评测计划与证据边界

本文件与 [cases.csv](cases.csv) 由 AI 协作生成。用例为合成输入和预期结果，未运行真实 MCP、未开展用户实验，也不代表生产推荐质量、订单链路或业务指标已通过。

## 评测分层

1. **规则审阅**：对照 Skill 和 PRD 检查约束、权限、营养未知与异常要求，不调用服务。
2. **离线原型**：打开 `prototype.html`，检查表单、页面切换、合成选择与异常按钮。只能证明概念交互表现。
3. **真实工具联调（未运行）**：用自己的授权账户核对工具 schema、鉴权、价格/单位、营业状态、订单查询与写入一致性；需另行明确写操作授权。
4. **用户任务研究（未开展）**：邀请目标用户完成相同任务，记录是否选定、时间与理解偏差；不能以 AI 自动点击充当用户实验。

CSV 的 `execution_status`、`actual_result`、`evidence` 默认分别为「未运行」「待填写」「待填写」。这指用例执行记录，独立于本轮文件/原型技术检查。人工运行后才能逐行填写，不能批量改成通过。

## 口径与门槛（目标，不是实测）

| 指标 | 分子 / 分母或计算方式 | 目标与使用边界 |
|---|---|---|
| 约束违规率 | 返回有解但违背硬约束数 / 有解输出数 | 关键门槛 0；需同时标出样本数 |
| 未确认写操作数 | 未明确确认而发生的写操作计数 | 关键门槛 0；原型无真实工具，需生产另测 |
| 数据来源误标数 | 合成/过期数据被说成实时返回的次数 | 关键门槛 0 |
| 异常路径覆盖率 | 已验证预期路径的异常用例数 / 计划异常用例数 | 目标100%；未执行前不报覆盖率 |
| 决策完成率 | 完成选餐任务人数 / 参与有效任务人数 | 待用户研究建立基线，暂不设提升幅度 |
| 决策耗时 | 从有效输入到选定方案的时间中位数与范围 | 分开统计用户停顿/接口时间；待研究 |

每次记录环境、日期、版本、输入、实际输出、是否满足验收和证据位置。关键错误阻断进入生产集成讨论；普通文案问题可记录后修订。合成用例通过也不证明泛化、安全或用户价值已达标。

## 执行方法

- CSV 中 `prototype`：在原型按 `steps` 操作，核对文本和允许动作。
- `review`：对照 [Skill](../../SKILL.md)、[MCP说明](../../MCP_INTEGRATION.md) 与 [PRD](PRD.md) 做桌面走查；HTML未实现的能力不能记为原型通过。
- `integration`：本轮禁用真实请求，保持未运行。
- 失败分类：输入校验、约束计算、状态/权限、数据来源、异常兜底、可访问性、服务集成；同时记录严重度和复现步骤。
