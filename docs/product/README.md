# 麦麦老友记 · 产品案例包

本案例把现有对话 Skill 的决策流程转化为可讨论的产品方案，关注需求拆解、工具编排、确认边界、异常体验与评测设计。文档、架构图与交互原型由 AI 协作制作；不构成任何人的独立设计经历、工具熟练度或上线成绩证明。

## 现有能力与新增设计

现有产品形态是由宿主 AI 执行的 [SKILL.md](../../SKILL.md)，通过宿主的 MCP 接口调用门店、菜单、营养、优惠券与核价等工具；本地 JSON 用于偏好与历史快照。接口要求见 [MCP_INTEGRATION.md](../../MCP_INTEGRATION.md)。仓库没有独立订单后端或已上线的图形界面。

本目录新增的是隔离的产品案例：HTML 不加载 Skill、不读取本地订单、不调用官方服务、不生成真实订单，也不证明所有 PRD 条目已实现。界面中的门店、餐名、价格、营养、状态均为合成示例；只有经账户授权的实时工具返回才可作为真实交易依据。

方案选择：保留对话 Skill 最贴近当前实现，但不便比较状态；直接开发生产 GUI 会引入认证、支付、订单一致性等额外依赖。本案例选择离线交互原型，用最小成本讨论输入、解释与确认过程，生产集成另行立项。
